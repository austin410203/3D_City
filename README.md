# 文明物語 Civilization Observer

Three.js 文明發展觀察模擬。選擇起始時代與地圖，文明會**自動**從第一批先民定居開始，開路、蓋房、建市集與工坊、補足水源／糧倉／電力、設置公共建設、監獄與軍營、興建時代奇觀，並在戰爭、災害、瘟疫、犯罪與革命中起起落落，永續演進。

模型全部來自 `sketchfab-ultimate16-materials-new.blend`，已匯出並以 meshopt 壓縮成 `models/town.glb`（約 5MB）。

## 永續演進的文明
文明**沒有終點**：科技累積到門檻就進入下一個時代（遠古部落 → 古埃及 → 東方古國 → 中世紀歐洲 → 西部拓荒 → 現代都市），抵達現代後仍持續產生科技突破。選單上選的是**起始時代**。

### 隨機事件（造成消長）
| 事件 | 觸發與影響 |
|---|---|
| ⚔️ 外敵入侵（各時代：敵對部落、海上民族、北方鐵騎、維京人、亡命之徒、敵國） | 敵軍沿道路進攻；軍力不足則邊境建築被燒毀成廢墟 |
| 🏹 對外遠征 | 帝國／獨裁政體主動出兵，勝則帶回戰利品與科技 |
| 🔥 部落衝突／農民暴動／街頭暴動 | 穩定度或滿意度低時發生，破壞商店與民居 |
| 🔥 城中大火 | 木造時代更容易發生，消防設施可控制火勢 |
| 🌋 地震、🌊 洪水／海嘯、🌪️ 沙暴、☀️ 乾旱、🥀 饑荒 | 依地圖地形與資源而定 |
| 🦠 瘟疫 | 貿易與缺水提高機率，醫院覆蓋可降低死亡 |
| 📉 經濟蕭條／✨ 黃金時代 | 景氣循環 |

廢墟燃燒結束後，居民會在原地重建。

### 犯罪與治安
人口、失業、低滿意度與貿易會推高犯罪率。搶劫、竊盜、勒索會降低當地滿意度；警局覆蓋區域有機會逮捕嫌犯並關進監獄（容量有限，爆滿時會放人）。軍營提供軍力以抵禦入侵。

### 政體演進
🪶 部落酋長制 → 👑 君主制（法老王朝、天子皇朝、封建王國…） → ⚔️ 帝國／🗳️ 民主共和／☭ 共產政權／🪖 軍事獨裁
- 和平演進：王權建立、稱帝建國、民主改革、還政於民、改革開放
- 劇烈轉變：穩定度過低時爆發革命或政變，走向哪種政體取決於貿易、教育、失業、工業比重、犯罪與戰敗次數
- 非民主政體執政越久越腐敗（王朝老化），最終可能被推翻
- 各政體影響滿意度、犯罪、軍力、科技與成長速度

## 觀看
- 速度：⏸ / 1× / 2× / 5× / 10× / 20×（空白鍵暫停，數字鍵 1–5 切換）
- 🎥 自動環繞鏡頭（R）
- 點擊任何建築查看資訊；左鍵拖曳平移、右鍵旋轉、滾輪縮放
- 右側：繁榮度、穩定度、犯罪率、科技進度、軍力、囚犯、地圖資源、人口消長曲線、住／商／產需求、📜 編年史
- 上方：時代、政體、進行中的事件
- 每個「地圖 × 時代」組合各自自動存檔

## 技術重點
- `data.js`：時代、地圖、建築規格（模型、數量、縮放、裝飾）
- `main.js`：自動發展 AI（格線道路規劃、依需求分區、資源升級、服務覆蓋、城市更新）、模擬、居民／交通、區塊烘焙
- 效能：靜態場景以 8×8 區塊合併為頂點色網格，角色每種模型烘焙一次，draw call 約 50–150
